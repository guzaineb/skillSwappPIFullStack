# Sons de notification

Ce dossier contient les sons de notification utilisés dans l'application.

## message.mp3

Son joué lorsqu'un nouveau message est reçu dans le chat.

Note: Vous devez ajouter un fichier MP3 nommé `message.mp3` dans ce dossier pour que les notifications sonores fonctionnent correctement.

Vous pouvez utiliser un son libre de droits comme ceux disponibles sur:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

Exemple de son recommandé: un "ding" court et discret pour notifier sans être trop intrusif.
